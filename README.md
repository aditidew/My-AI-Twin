# My-AI-Twin
Because one version of me wasn't enough. Meet my AI Twin.



Ever wished you could clone yourself?

Well... I kinda did.

This project is my AI Twin built using Agentic AI. It's designed to think, chat, and solve problems in a way that reflects how I would. Consider it my digital alter ego that doesn't need sleep, coffee, or lunch breaks.

## ✨ What It Does

- 💬 Holds conversations
- 🧠 Remembers context
- 🎯 Reasons through tasks
- ⚡ Takes actions using tools
- 👤 Mimics my style and personality
- 🚀 Keeps getting smarter

## 🛠️ Built With

- Agentic AI
- LLMs
- Memory Systems
- Tool Calling
- A questionable amount of curiosity

## 🎯 Why?

Because one version of me wasn't enough.

I wanted to explore Agentic AI by creating a digital version of myself that can assist, respond, and think through problems just like I would.

## 🚧 Status

Currently under development.
My AI twin is still learning how to be me without causing chaos.
